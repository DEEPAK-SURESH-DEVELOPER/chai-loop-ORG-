# Chai Loop Cafe Website

A mobile-first React + Vite landing page for Chai Loop Cafe, Kakkanad.

## Features

- Glassmorphism navigation with responsive mobile menu
- Cinematic chai hero using the existing Chai Loop cup artwork
- About, menu, experience, gallery, testimonials and location sections
- Interactive menu category tabs and product cards
- WhatsApp enquiry links using the cafe contact number
- Responsive layouts and reduced-motion support
- Local WebP food/menu visual crops derived from the cafe menu photographs supplied for this project

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
